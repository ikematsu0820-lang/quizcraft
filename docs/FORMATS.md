# 形式ごとのルール・見え方

相性の判定はすべて `rule_engine.js`（`modes()` と `FEATURES`）にまとめている。形式選びの次に出す「ルール設定」の候補は `play_style.js` の `FORMATS` にある。この文書と食い違ったら、コードのほうが正しい。

## 0. 共通の軸

| 軸 | 値（config） | 画面の呼び名 |
|---|---|---|
| 解答権 | `mode`: `buzz` / `normal` / `turn` / `nominate`（ほかに `solo`） | 早押し／一斉／順番／指名（ソロ挑戦） |
| 解答形式 | 問題の type で決まる（`free_oral` / `free_written`、選択式などは自動判定） | 口頭／手書き／ボタン |
| 配点 | `scoreType`: `uniform` / `ranked` / `hint` / `first`（`firstN`, `firstPts`）、`uniformPts`、連続正解ボーナス | 同じ点／早い順に高得点／ヒントが少ないほど高得点／先着 |
| 誤答 | 早押し: `buzzWrongAction` `next` / `end`、`buzzPenalty` `none` / `otetski` / `time_ban` / `rest`、他の人の押し順（引き継ぐ／全員押し直し）。順番: `turnWrongAction` `next` / `end`。減点（`wrongLoss` 系） | 継続／終了、誤答者、他の人の押し順、減点 |
| 勝敗 | `gameType`: `score` / `survival`（`survivalLives`, `survivalEndCount`）/ `winthrough`（`winTarget`, `winBy`, `winQuota`）/ `timerace` / `territory` / `panel` | 得点制／サバイバル／勝ち抜け／タイムレース |
| 時間 | `timeLimitEnabled` `on`、`timerKind` `per_q` / `pool` / `personal`、`timeLimitSeconds`、`answerSec`（押してから◯秒） | ① 制限時間 ② 解答時間 |
| スピード勝負 | 早い順に高得点（`scoreRanked`）、タイムレース、同点時は解答時間で順位（`tieBreak: 'time'`）、遅い人も脱落 | 時間のタブ |
| 結果発表 | `resultEachQ` `show` / `skip`、`playerScoreView` `score` / `score_rank` / `none` | 勝敗のタブ |
| 正解表示 | 下の「正解表示」の節 | デザイン › 正解表示 |

**組み合わせの大原則**
- 指名と順番は「1人ずつ答える」同士なので、どの形式でも同じ扱い。
- 口頭は全員が同時には答えられないので、一斉×口頭は無い（手書きにすれば一斉にできる）。
- 選択式・並べ替えは早押しを使わない。選択肢が見えている／並べる速さで競う形式なので、一斉にして早い順に高得点にする。
- 多答は早押しを使わない。先に押した人が簡単な答えを取っていってしまうため。順番か指名で、答えを開けていく。

## 1. 一問一答（free_oral / free_written）

- **解答権**: 早押し／一斉（手書きのみ）／順番／指名
- **解答形式**: 口頭（司会者が判定）／手書き（端末に書いて送信、司会者が判定）
- **早押し×手書き**（`wbOn()`）には専用の進め方がある。
  - `wbTiming`: 書いてから押す／押してから書く
  - `wbJudge`: 1人ずつ判定／押した順に並べて判定（解答ボード）
  - `wbAfterCorrect` `continue`: 正解した人は抜けて続ける（1抜け・2抜け…）。早い順に高得点、`wbWinCount` で打ち切り。
- **見出し**（`q.title`）: 問題文の上の小さな見出し（ジャンル名など）。
- **問題文の表示**: 「問題文を画面に出さない（司会者が読み上げる）」にすると、モニターには得点の一覧が出る（`readAloud`）。
- **正解表示**: 帯／全画面／問題文の下／1文字ずつ。問題ごとに「数字のカウント」も選べる。添えるもの（正解者名・獲得点・人数・正解率・解説）も付けられる。

## 2. 連想クイズ（assoc_*）

- ヒントを1つずつ開いていき、分かった時点で答える。
- 解答権・解答形式は一問一答と同じ。
- 配点の「ヒントが少ないほど高得点」（`scoreHint`）が使える。
- 司会者の画面に「ヒント1〜」のボタンが並び、押すとモニターで開く。
- 正解表示は一問一答と同じ（答えが文字の形式）。

## 3. 選択式（choice。〇×形式 `ox`、複数正解 `multiCorrect`）

- **解答権**: 一斉／順番／指名（早押しは無い）。
- **解答形式**: ボタン（自動判定）。
  - 「タップで即確定」がオンなら、選んだ瞬間に確定する。
  - オフなら「決定」を押す（選び直せる）。
- **配点**: 同じ点／早い順に高得点。
- **見せ方**（`choice_skin.js`）
  - 選択肢ボタンの形 `cSkin`: シンプル／放送パネル／カラーボタン／カプセル／カード
  - 色 `cPalette`: テーマ色／4色
  - 並び: 縦1列／横1列／格子（行・列を −＋ で変える）
  - 高さ: 標準／目いっぱい
    - 目いっぱいの時は、記号（A・B…）を左上に薄く大きく敷き、文字を中央に置く。
  - 問題文の見せ方 `qSkin`: 枠／テロップ帯／ボード／写真＋字幕
- **バラエティ枠**（`design.layoutTemplate === 'frame'`、`variety_frame.js`）: 選択式だけの画面の型。お題の帯 → 写真と名前 → カウントダウン → 押したボタンが光る → 答えとスタンプ。
- **解答オープン**: カードを1枚ずつめくる（`flip`）／選択人数の棒グラフ（`distribution`）。
- **正解表示**
  - 正解の選択肢が正解の色（`--th-good`）で光り、ほかは暗くなる。
  - ため演出、選択人数のバッジ、下の帯（正解者・人数・正解率・解説）。

## 4. 並べ替え（sort）

- 解答権・配点は選択式と同じ。
- 作る時は、項目を入れて、右の四角を正しい順にタップする。
- **正解表示**: 正しい順の一覧に差し替える。一括表示／1つずつ表示（間をあけて1行ずつ）。

## 5. 多答クイズ（multi / ranking、パネル指名）

- **解答権**: 順番／指名（早押し・一斉は無い）。
- 答えたものが当たっていれば、司会者がその答えのマスを開く。
  - 順番の時は、開いた人に得点が入り、次の人へ回る。
- 司会者の画面には次のボタンがある。どちらも得点は動かない。
  - 「広げる」（一覧を画面いっぱいに）
  - 「残りを開く」
  - ランキングだけ「下から開く」
- 種類: 通常／ランキング（◯位の答え）／**パネル指名**（`panel_board.js`。番号の付いたパネルを「4番、○○」と指名して答える。パネルごとに問題を付けることもできる）。
- 正解表示は、マスを開いた盤面のまま。

## 6. ゲーム（進行が決まっている形式）

| ゲーム | 仕組み | 解答権 |
|---|---|---|
| パネルクイズ（panel_quiz） | ジャンル×点数の盤面（1セット1盤面）。解答者がパネルを選び、その問題に答える。正解でパネルが自分の色になる。 | 指名（盤面から選ぶ） |
| ダウト（dobon） | 選択肢の中に当たり（罠）が混ざる。順番に1つずつ選び、当たりを引いたら脱落・減点。正解表示は、当たりを外れの色、ほかを正解の色で塗る。 | 順番 |
| 陣取りパネル（territory） | **盤面ごとで1問**。マスごとに表の字（例: 鮪）と答え（例: まぐろ）を用意し、モニターと解答者に盤面全体を出す（お題 `tpPrompt` を上に）。答える人が「13番、まぐろ」と言い（スマホの盤面から選んでもよい）、司会者が13番を押して〇✕。〇ならそのマスを取り、縦・横・ななめで挟んだ相手のマスを自分の色にひっくり返す。✕は、早押しなら他の人が押せる（誤答が「終了」の時はその回は終わり）、順番なら次の人、指名なら選び直し。得点＝マスの枚数。盤面は2〜8×2〜8。作る画面では盤面のマスを押して、問題文の欄に表の字、正解の欄に答えを書く（`q.tpCell`）。プレビューは盤面全体、お試しも盤面ごと遊べる。 | 早押し／順番／指名 |
| 数字予想（num_group → numgame。ブラックジャック形式） | 項目と数を用意し、順番に引いて目標の数に近づける。 | 順番 |

ゲームは、形式選びの次の「ルール設定」を飛ばす（遊び方が決まっているため）。別のセットからの問題の取り込みは、パネルクイズと数字予想ではできない。

## 7. 正解表示（デザイン › 正解表示、`reveal.js`）

値はセットの `currentConfig` に入る（以前の版で `design` に入っていた `revealStyle` / `revealWinners` も読む）。問題ごとの値は `q.*` で上書きする。

| 設定 | キー | 値 | 使える形式 |
|---|---|---|---|
| 判定演出 | `judgeCue` | `sound` 効果音のみ／`big` 〇✕を大きく／`big_name` 〇✕＋名前 | 早押し・順番・指名 |
| 正解後 | `revealTiming` | `host` 司会者の操作で（正解者の発表をはさむ）／`auto` 即正解表示 | 同上 |
| 表示方法 | `revealStyle` | `band` 帯／`full` 全画面／`inline` 問題文の下／`letters` 1文字ずつ（問題ごとに `count` 数字のカウント） | 答えが文字の形式 |
| 並べ方 | `revealSort` | `all` 一括表示／`one` 1つずつ表示 | 並べ替え |
| 表示タイミング | `revealPause` | `now` 即表示／`tame` ため演出（「正解は…」を約1.8秒） | 文字・選択式・並べ替え |
| 併せて表示 | `rvWinners`（既定オン）, `rvGain`, `rvCount`, `rvDist`（選択式）, `rvRate`（既定オン）, `rvNote`（既定オン） | `on` / `off` | 文字・選択式・並べ替え |
| 問題ごと | `q.themeId`, `q.revealStyle`, `q.publicRate`（世間の正解率％）, `q.commentary`（解説） | | |

**しくみ**
- 正解者名と獲得点は、司会者が `status.revealWinners`（名前の配列）と `status.revealGains`（`[{ n, g }]`）を送る。
- 一斉の時は、モニターが解答者の答えから正解者を数える。
- 判定演出は、司会者が判定のたびに `status.judgeCue = { ok, name, at }` を送る。モニターは15秒より古い合図を出さない。
- 「即正解表示」は、正解の判定のあと `setStep(4)` の代わりに `setStep(5)` へ進む（`stepAfterCorrect`）。
- 同じ発表を描き直す時（得点の更新など）は、動きを付けない（`rv-still`）。
- **画像の答え合わせ**（`q.imgReveal`: `blur` / `zoom`）は、モニター側の仕組みだけ残している。作る画面からは外した。次に作る「画像クイズ」で使う予定。

## 8. 結果の画面（テーマの色で描く）

- **正解者発表**: 早押し・順番・指名で、正解した人の名前、または「正解者なし」。
- **解答オープン**: 一斉で、全員の答えをカードでめくる。判定すると正解のカードが正解の色になる。
- **得点の一覧**: 読み上げの時、問題文の代わりに出す。
- **順位発表**（途中経過・最終結果）、**脱落者発表**（通過は正解の色、脱落は外れの色か灰色）。
